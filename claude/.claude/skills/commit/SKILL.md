---
name: commit
description: Review changes and create a commit
---

Review the current git status and changes, then create an appropriate commit following these guidelines:

1. Review all staged and unstaged changes using git status and git diff
2. Stage relevant files (ask if unsure what to stage)
3. Create a clear, concise commit message that describes what changed and why
4. Follow the project's commit message conventions based on recent commit history
5. NEVER mention Claude Code in commit messages
6. Create the commit with the standard format including the footer

After committing, show the git status to confirm success.
